04 · flow C
when_to_use
Choosing a flow

Which one, when?

FLOW A

Explore & prototype

  • The problem is still fuzzy
  • I need to compare directions
  • Stakeholders must see & feel it
FLOW B

Straight to production

  • The direction is already clear
  • A dev has a PR in flight
  • Fastest path to shipped design
FLOW C

Build the guideline

  • I need one source of truth
  • Figma & code have drifted apart
  • Agents need design context
05 · when to use
takeaways
What I'd leave you with

Design closer to the code

01
AI is my brainstorm partner. Spar with agents before committing to a direction.
02
Prototype in code, not just pixels. Prompt to build, then edit directly to finish.
03
Meet the work where it lives. Sometimes the fastest design tool is the dev's own PR.
04
Make design legible to agents. Ship the spec into the codebase, not just Figma.
