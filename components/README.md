# Components

Reusable **design-review UI elements** for building and annotating prototypes — for example:

- **Next / step buttons** to walk a reviewer through a flow.
- **Design-decision callouts** that surface the rationale behind a choice.
- Other shared review helpers (annotations, before/after toggles, etc.).

## Usage

Drop a component's HTML/CSS/JS into a prototype, or reference shared files from
[`/assets`](../assets). Keep each component small, self-contained, and framework-free
so it can be reused across any static prototype.
