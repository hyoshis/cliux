- Azure Container Apps
- Azure Application Gateway
- Azure Cache for Redis
- Azure Monitor
- Azure Key Vault

## Get started

```sh
azd init -t apptemplate-wordpress-on-aca
```

Use the Azure Developer CLI (azd) to deploy this template. [Learn more about azd](https://aka.ms/azd).
