# Awesome azd template catalog prototype

> 6 source-linked examples, not the full production catalog. Hero totals, filter counts and pagination are visual mocks; only the records below exist in this prototype. Repository stars and forks are GitHub snapshots, not deployment metrics. One shared record source powers human and agent views.

- [Get started with AI agents](../../templates/azure-samples/get-started-with-ai-agents/index.md): Build an AI agent; Python; Bicep.
- [Chat with your documents](../../templates/azure-samples/azure-search-openai-demo/index.md): Chat with documents; Python, TypeScript; Bicep.
- [Ask questions of your database](../../templates/azure-samples/rag-postgres-openai-python/index.md): Query a database; Python; Bicep.
- [Build a .NET knowledge assistant](../../templates/azure-samples/azure-search-openai-demo-csharp/index.md): Chat with documents; C# / .NET; Bicep.
- [Bring document chat to Java](../../templates/azure-samples/azure-search-openai-demo-java/index.md): Chat with documents; Java; Bicep.
- [Talk to your documents](../../templates/azure-samples/aisearch-openai-rag-audio/index.md): Chat with documents; Python, TypeScript, JavaScript; Bicep.

Filter with [prototype JSON](../../templates.json), then read a template's Markdown before choosing. The design-study-2 schema is a design sample, not the production contract. Unknown fields must not satisfy constraints. Use the [existing production catalog](https://azure.github.io/awesome-azd/templates.json) for the full inventory and follow its [schema](https://github.com/Azure/awesome-azd/blob/main/docs/templates-schema.md).
