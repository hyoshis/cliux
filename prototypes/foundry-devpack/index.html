Foundry DevPack: Redesigning the install experience.

Two redesigns improve today’s supported install flow and explore a possible future component-selection flow.

WinGet and terminal constraints
  • WinGet controls the output from “Found Microsoft Foundry DevPack…” through “Successfully installed.” That content can’t be customized.
  • The WinGet flow supports plain text only, with no color or text styling.
  • When setup finishes, WinGet automatically closes the second terminal window.
  • The installer can conditionally install integrations such as the Foundry Toolkit when Visual Studio Code is available. However, the main terminal can show only static text, so its summary can’t change based on detected apps.

Improves today’s supported one-step flow by explaining what Foundry DevPack installs and providing clear next steps.
