Install Foundry skill with azure.ai.agents

A proposed install flow that introduces the Microsoft Foundry skill at the point of consent, then makes its installation status explicit.

Design requirements

  • Yes installs the skill globally for use across projects.
  • Show the Foundry skill install prompt only if the skill isn’t installed.
  • If the user selects No, show the command to install the skill separately:npx skills add microsoft/azure-skills --skill microsoft-foundry
